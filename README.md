\# Real-Time Sign Language Recognition and Spoken Text Translation Engine using Computer Vision



A computer vision-based system that recognizes sign language gestures in real time through a webcam and converts them into text and spoken output.



\## Project Goal



The goal of this project is to develop an accessible communication system that helps bridge the communication gap between sign language users and people who may not understand sign language.



\## Planned Features



\- Real-time hand gesture detection

\- Sign language recognition using computer vision

\- Conversion of recognized signs into text

\- Text-to-speech conversion

\- Real-time webcam-based interaction



\## Technology Stack



\- Python

\- OpenCV

\- MediaPipe

\- Machine Learning

\- Text-to-Speech
